# 内部開発記録

この配下は開発者向けの実装・検証・受入履歴です。通常の製品・利用者向けドキュメントではありません。

[reports/](reports/) には、J.UI.各フェーズ・fix、過去の調査、失敗した実験、当時のPARTIAL/READY状態や後に置き換えられた知見を、その履歴として保存しています。親フェーズと個別fixの記録は独立して保持します。

現在の製品動作は [利用者向け資料](../user/README.md)、[管理者向け資料](../admin/README.md)、現在のコードから確認してください。任意の古いレポートを現行仕様とみなさないでください。

[H.3-C.1 teacher review package](../phase-h3c1-teacher-review-package.md) は内部検証資料ですが、生成スクリプトの固定出力先のため例外的に元の位置に残しています。
