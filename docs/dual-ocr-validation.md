# Ricoh + Uni-MuMER への変更と確認（2026-09-12）

この文書はページ全体を送信していた時点の検証記録です。その後、Ricohによる領域特定とUni-MuMERへの切り出し画像入力を追加しました。現在の処理はREADME.mdを参照してください。

## 実装

同じ画像をRicohとUni-MuMERへ逐次送信し、モデル別のOCR結果を保存します。Ornith Q8の照合・採点リクエストには、元画像と両OCRを添付します。照合段階には正解・ルーブリックを渡しません。

Uni-MuMERにはeval_handwrite.pyと同様の自由形式の転写を依頼し、JSON形式やenable_thinking=falseを強制しません。content優先・空の場合reasoning_contentという順序でLaTeX候補を抽出します。説明文は照合・採点へ渡さず、生レスポンスに保存します。reasoningが全体をちょうど2回繰り返した場合のみ重複半分を除きます。推論中の仮の数式を転写と断定しないため、元画像での照合が必要であることを付記します。

設定は既存の `models.ocr`（Ricoh）と `models.grader` を保ち、`models.math_ocr` を追加しました。モデルごとの `generation` と `request_timeout_seconds` で共通設定を上書きできます。旧runは新run名を指定して `--reuse-ocr-from` で移行します。再利用先に存在しない認識器は新規実行します。`--stage grade` は両方の成功済みOCRを要求します。
